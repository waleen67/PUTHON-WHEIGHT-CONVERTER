# Python Mini Calculator

A simple beginner project built with Python.
This program contains two small utilities:

1. **Weight Converter**
2. **Volume Calculator**

## Features

* Convert weight between kilograms and pounds
* Calculate volume using weight, width, and height
* Simple command line interaction
* Beginner friendly code

## Requirements

* Python 3.x
  Install Python from: https://www.python.org/




## Example

```
enter the weight: 70
kilograms or pounds? (k or l): k
your weight is:154.4 lbs.

enter the weight: 5
enter the width: 2
enter the height: 3
the area is 30
```

## Project Purpose

This project was created for practicing Python basics such as:

* variables
* user input
* conditional statements
* simple calculations
